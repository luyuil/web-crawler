# 新闻爬虫

一个用 Python 写的静态网页新闻爬虫：输入一个新闻列表页网址，自动抓取每条新闻的详情页，解析出**标题 / 日期 / 发布时间 / 链接 / 正文**，清洗去重后保存为 CSV，并输出统计结果（每天多少条、正文关键词 Top20）。带图形界面和命令行两种用法。

技术栈：`requests` + `BeautifulSoup` + `pandas`（界面用 Python 自带的 `tkinter`）。

## 功能特性

- 支持翻页模板：网址里含 `{}` 时自动替换成页码批量抓取，不含则只抓单个页面
- 解析详情页，提取标题、发布时间、正文
- 清洗：去除 HTML 残留标签、压缩连续空白；按标题 + 链接双重去重
- 保存 CSV（`utf-8-sig` 编码，Excel 直接打开不乱码）
- 统计：每天抓到多少条、正文关键词 Top20（用 jieba 分词）
- 礼貌爬取：请求间隔 0.5 秒（可配置）、失败自动重试 3 次、带 User-Agent
- 图形界面：输入网址点"生成"，实时显示进度；"清空"删除生成的 CSV

## 环境准备

需要 Python 3.8+（在 3.14 上开发测试）。本机装有多个 Python 版本时，注意安装和运行要用同一个解释器：

```bash
py -3.14 -m pip install requests beautifulsoup4 pandas jieba
```

## 使用方法

```bash
# 方式一：图形界面（不带参数运行，弹出窗口，在窗口里输入网址）
py -3.14 main.py

# 方式二：命令行模式（--url 必填）
py -3.14 main.py --url "https://www.chinanews.com.cn/scroll-news/news{}.html" --pages 3 --output data.csv

# 只抓一个页面（网址不含 {} 时，--pages 无效，固定抓 1 页）
py -3.14 main.py --url "https://www.chinanews.com.cn/scroll-news/news1.html" --output test.csv
```

**网址写法**：

- `https://.../news{}.html` —— 翻页模板，`{}` 会被替换成页码（从 `SITE` 配置的起始页开始），配合 `--pages` 抓多页
- `https://.../news1.html` —— 单页地址，只抓这一页的列表

## 输出文件

| 文件 | 内容 |
|---|---|
| `data.csv` | 主数据：标题、日期、发布时间、链接、正文 |
| `data_daily.csv` | 每天多少条（按日期排序） |
| `data_keywords.csv` | 正文关键词 Top20 及出现频次 |

## 更换目标网站

所有"跟某个网站绑定"的信息都集中在 `main.py` 顶部的 `SITE` 配置块里，换网站只改它：

| 配置项 | 含义 |
|---|---|
| `first_page` | 列表页从第几页开始 |
| `item` | 列表页中"每条新闻"的选择器 |
| `title_link` | 列表页中标题（含链接）的选择器 |
| `detail_title` | 详情页标题的选择器 |
| `detail_time` | 详情页完整发布时间的选择器 |
| `detail_content` | 详情页正文的选择器 |
| `encoding` | 网页编码；填 `None` 则自动检测 |
| `delay` | 两次请求的间隔秒数 |

找选择器的方法：浏览器里右键目标元素 → 检查 → 复制 selector。日期解析支持 `2026年10月06日`、`2026-10-06`、`2026/10/06` 三种格式。

**注意**：选择器是跟着网站结构走的。填一个结构不同的网址不会报错，但会抓到 0 条——这时需要按上面的方法更新 `SITE` 的选择器。

## 项目结构

```
main.py   # 主体：抓取、解析、清洗、统计、命令行入口、launch_ui()
ui.py     # 窗口界面（tkinter），被 main.py 引用
```

## 注意事项

- 仅用于学习目的，请控制抓取频率（默认已带 0.5 秒间隔），遵守目标网站 robots.txt
- 网站页面改版后选择器可能失效，表现为抓到 0 条或字段为空
- 关键词统计依赖 `jieba`，未安装时会跳过该统计，不影响主数据生成
